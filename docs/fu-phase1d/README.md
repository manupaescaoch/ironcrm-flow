# Fase 1D — candidatos isolados

Nenhum arquivo desta pasta é uma migração registrada ou função implantável automaticamente. SQL e endpoints são candidatos para banco descartável, sem dados reais, rede de mensagens ou produção. Implantação exige aprovação posterior.

Fase 1E: candidato CRM permite `moderator` e `user` com unidade somente na família Recepção/BV/M+3/M+32; admin preservado. Técnico permite admin/gerente/coordenador; Gerência admin/gerente; Comercial D+ somente admin/user. RPC Telegram existente não é alterada. Origem é derivada pelo endpoint, nunca pelo navegador.
