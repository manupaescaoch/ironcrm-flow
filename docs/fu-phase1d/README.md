# Fase 1D — candidatos isolados

Nenhum arquivo desta pasta é uma migração registrada ou função implantável automaticamente. SQL e endpoints são candidatos para banco descartável, sem dados reais, rede de mensagens ou produção. Implantação exige aprovação posterior.

Papéis atuais: `moderator` é exibido como Recepção no CRM, mas a confirmação Recepção/BV no banco permite somente `admin` ou `user` com unidade; `user` é exibido como Comercial. Portanto `moderator` permanece bloqueado, sem ampliação. Técnico permite admin/gerente/coordenador; Gerência admin/gerente. Origem é derivada pelo endpoint, nunca pelo navegador.
